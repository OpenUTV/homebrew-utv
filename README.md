# Homebrew OpenUTV Tap

Official Homebrew tap for [OpenUTV](https://github.com/OpenUTV/utv) — the lightweight, extensible, high-performance sequence player and viewer.

## Installation

```bash
brew install --cask openutv/utv/utv
```

Or tap first:

```bash
brew tap openutv/utv
brew install --cask utv
```

## Upgrading

```bash
brew upgrade --cask utv
```
